# FA2026_IACapstone_Citation_Analysis
Fall 2026 Bachelors in Information Analysis Capstone project presented by the University of Michigan's Institute of Social Research.

Please note that .env.example files have been included in order to demonstrate how to configure your personal .env file to protect API keys. If you are going to use your own API keys for this script, then please configure a .env file from the provided .env_example file in order to ensure key security.
